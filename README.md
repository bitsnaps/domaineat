# Domaineat

Domaineat is a SaaS platform for managing domain names.

**Tech Stack:**
- **Frontend**: Vue 3 + TypeScript + Pinia + Vue Router
- **Backend**: Hono (Node) 
- **Database**: PostgreSQL through REST API / SQLite (dev)
- **AI**: LangChain (multi-provider)

**Quick Start:**
```bash
# Install dependencies
pnpm install

# Development server
pnpm dev

# Build for production
pnpm build
```

**Key Features:**
- Domain portfolio management
- Financial tracking & analytics
- AI-powered prospecting
- Multi-registrar integration
- Automated valuation

**Documentation:**
- Comprehensive docs available in `./docs/` directory
- Search with `grep` to find specific documentation efficiently

**Development:**
- Use pnpm for all package operations
- Follow TypeScript and Vue.js best practices
- Test with Vitest before committing
